Password Generator 🔐

A simple and interactive Password Generator built using HTML, CSS, and JavaScript. It helps users generate random passwords based on their selected preferences.

Features

- Generates random passwords.
- Allows users to customize password length.
- Includes options for uppercase and lowercase letters, numbers, and special characters.
- Simple and user-friendly interface.
- Quickly generates a new password with a click.

Technologies Used

- HTML
- CSS
- JavaScript

How to Use

1. Open the project in your browser.
2. Select your desired password length.
3. Choose the character types you want to include.
4. Click the Generate Password button.
5. Copy the generated password if the copy feature is available.

Learning Outcomes

- JavaScript random number generation
- String manipulation
- Handling user input
- DOM manipulation
- Event handling
